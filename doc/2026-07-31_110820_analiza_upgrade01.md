## 3. ŠTO NEDOSTAJE — POTREBNO IMPLEMENTIRATI

### 3.1 Modularna arhitektura `app/` ❌
**Trenutno stanje:** Sav kod je u jednoj datoteci `mamba_voice.py` (1740 linija). Nema podjele po modulima.  
**Potrebna akcija:** Kreirati `app/` direktorij i razbiti kod na module prema tablici u sekciji 21.2 dokumentacije.

### 3.2 YAML konfiguracija ❌
**Trenutno stanje:** Konfiguracija je u `config/settings.py` — Python rječnik `SETTINGS`. Nema YAML-a.  
**Potrebna akcija:**
- Kreirati `config/settings.yaml` s globalnim postavkama.
- Kreirati per-book `work/output/<Knjiga>/config.yaml` generiran iz predloška.
- Migrirati `app/config_loader.py` da čita YAML umjesto Python modula.

### 3.3 CLI "GUI" s kursorskim tipkama ❌
**Trenutno stanje:** `interaktivni_izbornik()` koristi numerički unos (`1-5`, `Y`, `X`). Nema kursorske navigacije.  
**Potrebna akcija:** Implementirati `app/menu.py` s bibliotekom `curses` (Unix) ili `msvcrt`+ANSI (Windows) za:
- Kretanje ↑↓ kursorskim tipkama.
- Potvrda s Razmaknicom ili Enter.
- Highlight aktivne stavke.
- `X` na dnu svakog izbornika.

### 3.4 TEST granularnost — dropdown, header kao opcija ⚠️
**Trenutno stanje:**
- Postoji `SENTENCE_BY_SENTENCE` bool flag u konfiguraciji — prekruto (samo da/ne, bez trećeg nivoa "odlomak").
- `ADD_METADATA_HEADER` postoji ali se primjenjuje jednako i za TEST i za produkciju.

**Ispravan dizajn (nova specifikacija):**
- **Produkcija → UVIJEK čisti tekst bez headera** — direktna priprema za TTS→MP3.
- **TEST → header je OPCIJA** (DA/NE, default DA) — za usporedbu modela korisno.
- Statistika produkcije → zasebna `_stats.txt` datoteka (opcionalno), nikad u glavnoj datoteci.
- Granularnost: `odlomak` / `paragraf` / `rečenica` — CLI dropdown u OPCIJAMA.
- Vrijedi za TEST i produkciju (isti modus slanja segmenata AI-u).
- Proširiti `last_test.json` s `test_granularity`, `test_count`, `include_header`.

### 3.5 MP3 imenovanje `001_Ch01_part001.mp3` ❌
**Trenutno stanje:** MP3 datoteke dobivaju naziv po TXT datoteci poglavlja (npr. `001_prologue-pre-chapter-text.mp3`). Nema `ChXX` komponente.  
**Potrebna akcija:** Implementirati brojanje i imenovanje u `app/tts_engine.py`:
- Globalni brojač (`NNN`) kroz sve knjige/poglavlja.
- Poglavlje brojač (`ChXX`) reset po knjizi.
- Dio brojač (`partXXX`) reset po poglavlju.

### 3.6 ID3 metapodaci u MP3 ❌
**Trenutno stanje:** Nema metapodataka u MP3 datotekama.  
**Potrebna akcija:** Nakon generiranja svake MP3 datoteke, pisati ID3 tagove via `mutagen`:
- Artist = Autor knjige
- Album = Naslov knjige
- Title = `Chapter X — Part Y`
- Track = Globalni redni broj

### 3.7 Unificirana `FileManager` metoda ⚠️
**Trenutno stanje:** Postoje dvije odvojene funkcije `generiraj_sigurnu_putanju()` i `generiraj_sigurnu_mapu()`. Format sufiksa je `(001)` za oba.  
**Potrebna akcija:**
- Objediniti u klasu `FileManager` u `app/file_manager.py`.
- Standardizirati suffix format: direktoriji → `_001`, datoteke → `(001)` (ili oboje `_001` — treba odlučiti).
- Dodati `book_output_dir()` i `audiobook_dir()` metode s automatskim suffix-incrementom.
- Parametar `suffix_if_exists` za eksplicitno upravljanje.

### 3.8 Per-book `config.yaml` ❌
**Trenutno stanje:** Nema per-book konfiguracije. Svi parametri su globalni u `config/settings.py`.  
**Potrebna akcija:** Pri prvom obradi knjige kreirati `work/output/<Knjiga>/config.yaml` iz predloška profila s book-specifičnim podacima (naslov, autor, system prompt, parametri).

### 3.9 API provideri — Ollama i .env ❌
**Trenutno stanje:** Podržani su samo LM Studio, OpenAI, Gemini, Qwen. Nema Ollama (lokalni ni cloud). API ključevi su definirani u `settings.py` kao plain text — ne koristi se `.env`.

**Potrebna akcija:**
- Dodati `ollama_local` provider (endpoint: `http://127.0.0.1:11434/api`).
- Dodati `ollama_cloud` provider.
- Dodati `custom` provider (generički adapter).
- Migrirati sve API ključeve u `.env` datoteku u root direktoriju.
- Čitanje ključeva via `python-dotenv` (`os.getenv`).
- `.env` dodati u `.gitignore`; `.env.example` s praznim vrijednostima commitati u Git.
- Dodati `python-dotenv` u `requirements.txt`.

## 4. PROBLEMI U POSTOJEĆEM KODU

### 4.1 Konfiguracija nije YAML — Python modul
`config/settings.py` koristi Python rječnik `SETTINGS`. Prednost je čitljivost multi-line stringova, ali narušava principe:
- Mješanje koda i podataka.
- Ne može se editirati bez Python znanja.
- YAML podržava multi-line stringove jednako dobro (`|` literal block).

**Rizik migracije:** Nizak — sve vrijednosti su jasno mapirane.

### 4.2 Spagetti kod — jedna datoteka 1740 linija
`mamba_voice.py` sadrži: parsiranje, čišćenje, prevođenje, TTS, progress, CLI, history, file management — sve zajedno. Nema separacije odgovornosti.

**Rizik refactoringa:** Srednji — funkcije su dobro dokumentirane i relativno izolirane, ali globalne varijable (`_TRENUTNA_PUTANJA_KNJIGE`, `_UCITANI_LIKOVI`, `_PREKID_ZAHTJEVAN`) trebaju pažljivu migraciju.

### 4.3 Globalne varijable — antipattern
```python
_TRENUTNA_PUTANJA_KNJIGE: str = ""
_UCITANI_LIKOVI: dict[str, str] = {}
_PREKID_ZAHTJEVAN: bool = False
_HISTORY_IZLAZNI_DIR_TEKST: str = ""
_HISTORY_IZLAZNI_DIR_MP3: str = ""
```
Potrebno zamijeniti s instance varijablama unutar klasa (`Translator`, `TTSEngine`).

### 4.4 `prikazi_checkbox_izbor()` nije definiran u analiziranom kodu
Funkcija `prikazi_checkbox_izbor()` se poziva u `interaktivni_izbornik()` ali nije vidljiva u pregledanom dijelu koda. Pretpostavka: postoji ali bez kursorske navigacije.

### 4.5 Duplikacija API pozivnog koda
`prevedi_odlomak_lm_studio()` i `prevedi_recenicu_lm_studio()` sadrže skoro identičan payload build + urllib poziv kod (~60 linija duplikacije). Trebaju se objediniti u jednu privatnu metodu `_api_call(payload)`.

### 4.6 `segmentiraj_poglavlja_po_odlomcima()` je mrtav kod
```python
def segmentiraj_poglavlja_po_odlomcima(tekst):
    poglavlja = segmentiraj_poglavlja(tekst)  # samo poziva drugu funkciju
    return poglavlja
```
Wrapper bez ikakve dodane logike — može se ukloniti.

### 4.7 Direktorij struktura razlikuje od specifikacije
**Postojeće:**
```
input/
input/processed_text/
output/text/
output/mp3/
```
**Specifikacija:**
```
work/input/
work/output/<Knjiga>/
work/translated/<Knjiga>/
work/audiobooks/<Knjiga>/
```
Potrebna migracija direktorij strukture.

## 7. ZAKLJUČAK

`mamba_voice.py` v1.0.7 ima **solidnu funkcionalnu jezgru** (prevođenje, TTS, checkpointing, progress) koja vrijedi sačuvati i migrirati. Glavne slabosti su arhitekturne prirode:

1. **Sve u jednoj datoteci** — refactoring u `app/` module je najvažniji zadatak.
2. **Python konfiguracija umjesto YAML** — migracija je straightforward ali potrebna.
3. **Nema kursorske navigacije** — zahtijeva novi kod u `app/menu.py`.
4. **TEST ≠ PRODUKCIJA razlikovanje headera** — manja izmjena logike.
5. **MP3 imenovanje i ID3** — novi kod, biblioteka `mutagen`.

Pozitivno: kod je dobro dokumentiran (docstrings), funkcije su relativno kratke i izolirane, error handling je konzistentan, atomic write za checkpointe je već implementiran. Sve ovo čini migraciju predvidljivom i sigurnom.

### 3.10 `memorija.json` — GLOSSARY i GRAMMAR_FIXES ⚠️
**Trenutno stanje:** `likovi_memorija.json` sadrži samo CHARACTER profile (flat rječnik `{ime: opis}`).  
**Potrebna akcija:** Proširiti na tri sekcije:
```json
{
  "CHARACTERS": {},
  "GLOSSARY": {},
  "GRAMMAR_FIXES": {}
}
```
Renaming: `likovi_memorija.json` → `<Knjiga>_memorija.json`.
